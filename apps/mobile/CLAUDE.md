# Mobile rules (Expo, React Native, Android first)

- Health Connect and push need a development build (`eas build --profile development` or the
  `Android APK` GitHub workflow). Expo Go cannot load them.
- `EXPO_PUBLIC_API_URL` is the API origin WITHOUT `/api/v1` (`src/api.ts` appends it). Release builds must use HTTPS.
  Dev on a phone: run `scripts/dev/phone-ip.sh` for the LAN address; `localhost` on the phone is the phone.
- Tokens: `expo-secure-store`, never AsyncStorage. Offline writes carry a client UUID as `Idempotency-Key`.
- Mark health data or captures "synced" only after the API accepts them.
- `android/` is generated by `expo prebuild` and is not committed. Same signing key for every release forever.
- Check before PR: `npx tsc --noEmit`.
